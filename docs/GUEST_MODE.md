# 游客模式边界与验收

游客入口为 `/guest`；小程序首页另有“Surface 能力顾问”入口，复用此网页。此模式无需注册或 License，可选择产品 Part Number，填写模型规模、游戏目标、生成式 AI 工作流、生产力软件及自由描述，按用途取得工程候选，并查看 AI 模型容量、游戏、生成式 AI、生产力的分栏说明。无匹配候选时应明确提示，不能把空结果写成已推荐产品。

游客接口仅为 `/api/guest/skus`、`/api/guest/recommendations` 和 `/api/guest/advisor/{part_number}`。对导入 SKU 使用显式字段白名单：公开显示产品名称、料号、处理器描述、内存、存储、CPU/GPU 名称与操作系统；不返回 ERP 价格、原始配置、导入来源引用、工作簿行、内部备注或哈希。游客需求表单不提交预算，接口也明确拒绝预算筛选；不假装按隐藏价格排序。结果卡片应显示“工程估算”证据级别与限制，不能用用户填写的目标 FPS 充当实测值。

AI 模型 8B/32B/70B/120B 的 4-bit 内存筛选是**工程估算**，不是指定模型版本、软件兼容性或 Token/s 实测。游戏、生成式 AI 与生产力模块保留官方平台资料、工程判断、未知结果和来源链接；平台资料不自动转为本 SKU 的性能承诺。

原 `/api/catalog/*`、内部推荐、FAQ、客户报告、TCO、账号和管理员接口仍使用原有登录、审批与 License 边界。游客页面不提供报告下载。公网部署应保留请求频率限制，且不要将测试数据、授权原始工作簿或秘钥放入公开静态目录。

发布前检查：

可先运行匿名只读预检：`python scripts/verify-public-guest.py https://surfacedmp.com`。脚本检查游客页面、产品列表、包含模型规模与生产力用途的推荐、公开响应字段白名单，以及未登录目录和报告返回 401；不会打印料号、价格或用户数据。本机网络不通时可在受控服务器上运行同一脚本。预检不能替代小程序 iOS/Android 真机交互或正式版发布核对。

1. 先在受保护的预览环境验证 `GET /guest` 和游客三个接口无需登录可用；再确认内部目录、报告与管理员接口在匿名状态返回 401。
2. 用一条带哨兵价格、原始配置、来源引用和备注的测试 SKU 检查响应中均不出现这些字段；仓库 `test_guest.py` 已覆盖此断言。
3. 核对实际公开料号与配置是否允许对游客展示；不要将内部价格或采购条款误放入页面。需要收窄公开范围时，应先增加独立的发布许可标记，不能依赖前端隐藏。
4. 小程序 iOS/Android 真机分别验证游客入口、产品切换、四个能力模块、返回路径与授权版入口；不得以模拟器结果代替。
5. 仅修改 `/guest` 网页且 URL、接口契约和小程序原生逻辑不变时，小程序 `web-view` 与浏览器共用已部署网页，无需重新上传小程序代码包，但必须分别做网页与小程序真机回归。修改小程序首页、导航、下载或其他原生代码时，须重新上传、审核和发布代码包。上线前维持草稿 PR，未经确认不合并 `main`。
