# Surface Laptop Ultra 能力顾问 V3.0 验收

此文档区分“本机自动检查通过”和“目标环境尚未验收”。草稿 PR #6 不代表正式生产发布；不要合并 `main`，直到下列目标环境与商业授权检查完成。

## 本机自动验收

启动 `scripts/start-local.ps1 -Port 8010` 后，在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-local.ps1 -Port 8010
```

脚本只读取本地接口，不修改 SKU、账号或业务数据。它核对健康检查与数据库、中文首页、已导入 SKU 的唯一性、按 SKU 的能力映射和部署路线、至少 200 条 FAQ、TCO 初始值，以及“选项 + 自由描述 → 产品候选 → 对应 SKU 报告”的链路与版权声明。开启 `CAPABILITY_REQUIRE_AUTH=1` 的环境须用 `-Token` 传入已登录且 License 有效的会话令牌；不要把令牌写入仓库、工单或截图。

## 浏览器人工验收

1. 从首页选择一个低价及一个高内存 SKU，核对价格排序、两列表格中的处理器 9+9 或 10+10 核、共享显存与平台 300 GB/s 带宽、AI/游戏/生成/生产力板块和未知性能字段。
2. 在“按使用需求推荐产品”同时输入选项与自由描述，点击候选卡片“查看此配置的详细能力并生成报告”。核对报告仅包含本次所选需求及所点 SKU，不将估算写成实测。
3. 点击“打开独立报告页并打印／另存为 PDF”，在浏览器保存对话框核对文件名 `按描述需求配置报告-<SKU>.pdf`；逐页检查中文、公司 Logo 和页脚版权。浏览器/打印驱动可能覆盖建议文件名，须以最终保存文件为准。
4. 打开该 SKU 的模型部署指南，核对试验路线、RAG/微调取舍、注意事项及打印报告；在 TCO 修改采购价、电费、云端单价、业务量等值，核对结果联动、回本月数和 PDF 文件名。
5. 本地演示模式下可匿名浏览；在独立测试环境开启 `CAPABILITY_REQUIRE_AUTH=1` 后，未登录的目录、FAQ、部署、顾问和报告 API 应返回 401；过期 License 应返回 403。登录后同一标签页的页面功能应正常。管理员须先配置并启用 MFA 才能审批用户或管理 License。

## 发布前必须完成，当前不能代替实测

- 在实体 Windows 11 Pro ARM64 设备上从干净系统安装 Python 与依赖，确认解释器架构、驱动、GPU 后端、模型许可、目标软件兼容性和持续负载稳定性。Windows x64 CI 不能替代 ARM64 验收。
- 用企业测试集记录实际模型版本/量化/上下文、首 token 延迟、Token/s、内存峰值与游戏 FPS；没有测得的数值保持“未知”。容量筛选和官方平台声明不得伪装成 SKU 实测。
- 配置正式 SMTP、管理员 MFA 主密钥托管与恢复流程、HTTPS 反向代理、备份/恢复、密钥轮换和安全审查；验证真实邮件收发与过期/重放路径。
- 核实“微软商用 Surface 授权 ADR”身份、商标与图形使用权、数据来源许可、SKU 价格有效期和对外法律文字。

验收记录建议填写：日期、设备 Part Number、Windows 版本、架构、驱动/运行时版本、测试人、测试数据来源、结果、截图/日志路径，以及尚未通过的阻塞项。不要在记录中包含密码、MFA 种子、会话令牌或企业原始私有数据。
